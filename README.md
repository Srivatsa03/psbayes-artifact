# PSBayes: Per-Seed Bayesian Estimator for Residual Risk in Greybox Fuzzing

**Artifact submission** — anonymous reproducibility package for the paper
*"A Bayesian Approach to Estimating Residual Risk of Fuzzing."*

This repository contains the source code, raw fuzzing data, pre-computed
results, and paper figures required to reproduce every table and figure
referenced in the paper.

## 3. How to reproduce the results

### Quick verification (no recomputation, ~1 minute)

The pre-computed CSVs in `data/csv/` already contain every per-round
estimate and every aggregate metric reported in the paper. You can
inspect them directly:

```bash
ls data/csv/
# 8 per-benchmark CSVs + summary tables for the RQs
```

Key files:
- `data/csv/<benchmark>.csv` — per-round estimates for each benchmark
- `data/csv/table2_complete.csv` — aggregate metrics (Table II / III)
- `data/csv/rq4_psbayes_stop_avg.csv` — RQ4 stopping-rule frontier
- `data/csv/coverage_sat_sweep_trials.csv` — coverage-saturation comparison

### Full re-run (regenerates everything, ~5-10 minutes)

```bash
jupyter notebook main_analysis.ipynb
```

Run cells in order from top to bottom. The notebook will:
1. Parse the raw fuzzing data from `data/raw/`
2. Compute every estimator on every benchmark (LLaplace, LGT, Bayes
   Factor variants, Posterior Mean, OracleFree, PSBayes95/99/PM)
3. Regenerate every CSV in `data/csv/`
4. Produce every figure used in the paper

All estimators (baselines and ours) are evaluated against the same
TrialsToDisc (TTD) ground truth.

## 6. Raw data format

Each `data/raw/<benchmark>_run2.txt` is the output of a single fuzzing
campaign with extended instrumentation. Each line is tagged with a
four-character label:

```
__SUCCS__ pointID, seedID:trials      # winning seed for that round
__FAILS__ pointID, seedID:count, ...  # failed-seed attempts in the round
__FEATS__ pointID, features           # new coverage features discovered
__LLAPL__ pointID, llaplace           # fuzzer-internal LLaplace estimate
__LGDTU__ pointID, lgt                # fuzzer-internal LGT estimate
__MXFRK__ pointID, maxfork            # per-seed max execution count
__AVFRK__ pointID, avgfork            # per-seed average execution count
__RATES__ pointID, rate               # trials/sec
```

The notebook's `parse_file()` function (CELL-07) consumes this format.

## 7. Key formulas (cross-references the paper)

### Bayes Factor (PSBayes99)
$$
\theta^* = \frac{1}{(m^* + 1)(\mathcal{R}^{1/l} + 1)}, \qquad
T_{99} = \frac{\ln(0.01)}{\ln(1 - \theta^*)}
$$

with $\mathcal{R} = 100$ (Kass--Raftery decisive evidence threshold) and
$l$ the number of discovery rounds.

### Per-Seed difficulty parameter
$$
m^*_{PS} = \frac{\sum_s w_s / p_s^{\text{upper}}}{\sum_s w_s},
\quad w_s = \alpha_s + \beta_s, \quad p_s^{\text{upper}} = F^{-1}_{\text{Beta}}(0.95;\; \alpha+\text{succ}_s,\; \beta+\text{fail}_s).
$$

### Posterior Mean (PSBayesPM)
$$
T^{\text{PostMean}} = \frac{m^* \cdot n_{\text{terms}}}{1 - \exp(-m^* \cdot \hat{P}_{\text{sum}})}.
$$
